# Naija Bites Kitchen

## Project Description
A responsive restaurant and food ordering website built with React JS. Users can browse the menu, search and filter dishes, add meals to a cart, place an order and send a message through a validated contact form.

## Technologies Used
- React JS (Vite), JavaScript (ES6+), JSX
- React Router, Context API, Hooks (useState, useEffect, useContext, custom hook)
- HTML and CSS (Flexbox, Grid, media queries)
- Local Storage (cart is saved between visits)

## React Concepts Implemented
Functional components, props, JSX, useState, useEffect, useContext, custom hook (useLocalStorage), React Router, controlled forms with validation, event handling (onClick, onChange, onSubmit), `.map()` / `.filter()` / `.reduce()`, responsive design.

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run: `npm install`
4. Start the application: `npm run dev`

## Build for production
`npm run build`
